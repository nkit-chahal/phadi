Reinforcement Learning

Learning through interaction: Agents, Environments, and Reward Maximization

📌 Quick Summary

🤖
Agent & Environment

The Agent takes actions in an Environment to transition states and receive rewards.

💎
Reward Function

The signal the agent tries to maximize. Defines the goal of the learning process.

📜
Policy (π)

A mapping from states to actions. The "strategy" or "brain" of the agent.

📖 Key RL Frameworks

1. Model-Free vs Model-Based

  • Model-Free: Agent learns directly from experience (e.g., Q-Learning, PPO).
  • Model-Based: Agent builds a model of the environment's transitions to plan ahead.

2. Exploration vs Exploitation

The classic tradeoff: Should the agent try new things to find better rewards (Exploration) or stick to what it knows works (Exploitation)? Often handled via ε-greedy strategies.

3. RLHF (Reinforcement Learning from Human Feedback)

Critical for modern LLMs (ChatGPT). Uses human rankings to train a reward model, which then fine-tunes the LLM via PPO (Proximal Policy Optimization).

🎤 Interview Q&A

Q1 What is the Bellman Equation? +

Answer:

The Bellman Equation decomposes the value of a state into the immediate reward plus the discounted value of the next state: V(s) = R(s, a) + γ * V(s'). It is the basis for most RL algorithms.

Q2 Explain RLHF in the context of LLMs. +

Answer:

  1. Pretraining: Train LLM on massive text data.
  2. SFT: Supervised Fine-Tuning on human-written demonstrations.
  3. Reward Modeling: Humans rank LLM outputs; a Reward Model learns these preferences.
  4. PPO: The LLM is fine-tuned to maximize the reward model's score using RL.

✍️ Practice Problem

What is the 'Credit Assignment Problem' in RL?

It's the difficulty of determining which specific action(s) in a long sequence led to a reward received much later (e.g., which move in a chess game caused the win). Solutions include Reward Shaping and Discounting (γ).
