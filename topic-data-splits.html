Train/Val/Test Split

Properly splitting data for unbiased model evaluation

📌 Quick Summary

📚
Training Set (70-80%)

Model learns patterns from this data

🔧
Validation Set (10-15%)

Tune hyperparameters, early stopping, model selection

✅
Test Set (10-15%)

Final unbiased evaluation. NEVER use for tuning!

📖 Why Three Splits?

The Problem

If you tune hyperparameters on test set, you're indirectly fitting to test data. Your "test accuracy" becomes optimistic and won't generalize.

The Solution

  • Training: Fit model parameters (weights)
  • Validation: Fit hyperparameters (learning rate, layers, etc.)
  • Test: Completely untouched until final evaluation

Typical Ratios

Large Dataset (>100K samples):   80% / 10% / 10%
Medium Dataset (10K-100K):       70% / 15% / 15%
Small Dataset (<10K):            Use K-Fold Cross-Validation

Time Series:                     Train on past, test on future
                                 (NO random shuffle!)

🔄 Cross-Validation

K-Fold Cross-Validation

  • Split data into K equal parts (folds)
  • Train on K-1 folds, validate on 1 fold
  • Repeat K times, average results
  • Common K: 5 or 10
Fold 1: [Val] [Train] [Train] [Train] [Train]
Fold 2: [Train] [Val] [Train] [Train] [Train]
Fold 3: [Train] [Train] [Val] [Train] [Train]
Fold 4: [Train] [Train] [Train] [Val] [Train]
Fold 5: [Train] [Train] [Train] [Train] [Val]

Final score = Average of all 5 fold scores

Stratified K-Fold

  • Maintains class distribution in each fold
  • Must use for: Imbalanced classification

Time Series Split

  • Train on past, validate on future
  • Never shuffle! Would cause data leakage

💻 Code Examples

Python Basic Train/Val/Test Split 
from sklearn.model_selection import train_test_split

# First split: separate test set
X_temp, X_test, y_temp, y_test = train_test_split(
    X, y, test_size=0.15, random_state=42, stratify=y
)

# Second split: train and validation
X_train, X_val, y_train, y_val = train_test_split(
    X_temp, y_temp, test_size=0.18, random_state=42, stratify=y_temp
)
# 0.18 of 0.85 ≈ 0.15 of total

print(f"Train: {len(X_train)}, Val: {len(X_val)}, Test: {len(X_test)}")
# Roughly 70-15-15 split
Python K-Fold Cross-Validation 
from sklearn.model_selection import KFold, StratifiedKFold, cross_val_score
from sklearn.ensemble import RandomForestClassifier

# Basic K-Fold
kfold = KFold(n_splits=5, shuffle=True, random_state=42)

# Stratified K-Fold (for imbalanced data)
skfold = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)

# Using cross_val_score
model = RandomForestClassifier()
scores = cross_val_score(model, X, y, cv=skfold, scoring='f1')

print(f"F1 Scores: {scores}")
print(f"Mean: {scores.mean():.3f} (+/- {scores.std()*2:.3f})")

# Manual K-Fold (when you need more control)
for fold, (train_idx, val_idx) in enumerate(skfold.split(X, y)):
    X_train, X_val = X[train_idx], X[val_idx]
    y_train, y_val = y[train_idx], y[val_idx]
    
    model.fit(X_train, y_train)
    score = model.score(X_val, y_val)
    print(f"Fold {fold+1}: {score:.3f}")
Python Time Series Split 
from sklearn.model_selection import TimeSeriesSplit

# Time series data - NEVER shuffle!
tscv = TimeSeriesSplit(n_splits=5)

for fold, (train_idx, val_idx) in enumerate(tscv.split(X)):
    print(f"Fold {fold+1}:")
    print(f"  Train indices: {train_idx[0]} to {train_idx[-1]}")
    print(f"  Val indices: {val_idx[0]} to {val_idx[-1]}")
    
# Output:
# Fold 1: Train [0-16], Val [17-33]
# Fold 2: Train [0-33], Val [34-50]
# ... and so on (train grows, val shifts forward)

🎤 Interview Questions & Answers

Q1 What's the difference between validation and test set? +

Answer:

  • Validation: Used during training for hyperparameter tuning, early stopping, model selection. Can look at it multiple times.
  • Test: ONLY used once at the very end for final, unbiased evaluation. Should be treated as "locked away."

If you tune based on test performance, you're effectively training on it, and your results won't generalize.

Q2 When would you NOT use random shuffle for splitting? +

Answer:

  • Time series data: Shuffling would leak future information into training (data leakage)
  • Grouped data: If samples from same source (e.g., same patient) must stay together
  • Sequential data: When order matters for the problem

Always split by time for time series: train on past, predict future.

Q3 What is stratified sampling and when to use it? +

Answer:

Stratified sampling maintains the same class distribution in each split as the original data.

When to use:

  • Imbalanced classification (e.g., 95% negative, 5% positive)
  • Multi-class with varying class frequencies
  • Small datasets where random split might not preserve distribution

Example: If 5% fraud in data, each fold should also have ~5% fraud.

Q4 How did you split data in your projects? +

Answer (Example Answer):

  • YOLOv5 (Lincode): 80/10/10 stratified by defect type. Used YOLO's built-in validation for mAP tracking.
  • Crop yield forecasting (AgriWatch): Time-based split - trained on 40 years, validated on 5 years, tested on most recent 5 years. Never shuffled.
  • RAG evaluation (Trident): Created held-out test set of real operator queries, never used during retrieval tuning.
