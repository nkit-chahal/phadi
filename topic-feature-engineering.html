Feature Engineering

Transforming raw data into features that improve model performance

📌 Quick Summary

📏
Scaling

Normalization [0,1] or Standardization (mean=0, std=1)

🔤
Encoding

One-hot for nominal, Label/Ordinal for ordered categories

🔀
Feature Creation

Interaction terms, polynomial features, domain-specific transforms

📖 Key Techniques

1. Scaling / Normalization

  • Min-Max Normalization: Scale to [0, 1]. x' = (x - min) / (max - min)
  • Standardization (Z-score): Mean=0, Std=1. x' = (x - μ) / σ
  • Robust Scaler: Uses median and IQR, robust to outliers

When to use:

  • Gradient-based models (neural nets, linear regression): Always scale!
  • Tree-based models: Not required, but often still helps

2. Categorical Encoding

  • One-Hot: Creates binary column per category. For nominal data (no order).
  • Label Encoding: Assigns integers. For ordinal data (has order).
  • Target Encoding: Replace category with mean of target. Powerful but can leak.
  • Frequency Encoding: Replace with frequency count.

3. Handling Missing Values

  • Drop: If very few missing values
  • Mean/Median/Mode: Simple imputation
  • KNN Imputer: Use similar samples
  • Add indicator: Binary column for "was_missing"

4. Feature Creation

  • Polynomial Features: x², x³, x₁×x₂
  • Log Transform: For skewed distributions
  • Binning: Convert continuous to categorical
  • Date Features: Extract day, month, year, day_of_week, is_weekend
  • Text Features: TF-IDF, word counts, embeddings

5. Feature Selection

  • Correlation: Remove highly correlated features
  • Variance Threshold: Remove low-variance features
  • Feature Importance: From tree-based models
  • RFE: Recursive Feature Elimination
  • L1 Regularization: Automatic feature selection

Python Scaling and Encoding Pipeline 
from sklearn.preprocessing import (
    StandardScaler, MinMaxScaler, RobustScaler,
    OneHotEncoder, LabelEncoder
)
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline

# Define column types
numeric_features = ['age', 'income', 'balance']
categorical_features = ['city', 'gender', 'occupation']

# Create preprocessor
preprocessor = ColumnTransformer(
    transformers=[
        ('num', StandardScaler(), numeric_features),
        ('cat', OneHotEncoder(drop='first', handle_unknown='ignore'), 
         categorical_features)
    ]
)

# Combine with model in pipeline
pipeline = Pipeline([
    ('preprocessor', preprocessor),
    ('classifier', LogisticRegression())
])

# Fit and predict
pipeline.fit(X_train, y_train)
predictions = pipeline.predict(X_test)
Python Handling Missing Values 
from sklearn.impute import SimpleImputer, KNNImputer
import pandas as pd

# Check missing values
print(df.isnull().sum())

# Simple imputation
imputer = SimpleImputer(strategy='median')  # or 'mean', 'mode'
df['age'] = imputer.fit_transform(df[['age']])

# KNN imputation (uses similar samples)
knn_imputer = KNNImputer(n_neighbors=5)
df_imputed = pd.DataFrame(
    knn_imputer.fit_transform(df),
    columns=df.columns
)

# Add missing indicator
df['age_was_missing'] = df['age'].isnull().astype(int)
df['age'] = df['age'].fillna(df['age'].median())

🎤 Interview Questions & Answers

Q1 When to use normalization vs standardization? +

Answer:

  • Normalization (Min-Max): When you need bounded range [0,1], for neural networks with bounded activations, image pixels
  • Standardization (Z-score): When data has outliers, for SVM, Logistic Regression, algorithms assuming normal distribution
  • Robust Scaler: When you have many outliers

For most cases, Standardization is safer as it's less affected by outliers.

Q2 What is one-hot encoding and when does it fail? +

Answer:

One-hot encoding creates a binary column for each category. Category "red" becomes [1,0,0], "blue" becomes [0,1,0].

When it fails:

  • High cardinality: 1000 categories = 1000 columns (memory issues)
  • Tree-based models: Can be inefficient, target encoding often better
  • New categories at test time: Need handle_unknown='ignore'

Alternatives: Target encoding, embedding layers, hashing

Q3 How do you handle missing values? +

Answer:

Depends on the amount and pattern of missingness:

  • < 5% missing: Simple imputation (mean/median) usually fine
  • 5-20% missing: KNN imputation or model-based imputation
  • > 20% missing: Consider dropping feature, or add "is_missing" indicator
  • MNAR (Missing Not At Random): Missingness is informative, add indicator

Always analyze WHY data is missing before choosing method!
