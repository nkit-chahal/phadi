AI Agents & Autonomous Systems

LLMs that don't just talk—they reason, act, and solve complex multi-step problems

📌 Quick Summary

🧠
Reasoning (ReAct)

The "Reasoning + Acting" paradigm. The agent thinks out loud before using a tool.

⚒️
Tool Use (Function Calling)

LLMs generating structured JSON to call external APIs, databases, or search engines.

🤝
Multi-Agent Systems

Coordinating multiple specialized agents (e.g., Researcher + Writer) to work together on a single goal.

📖 The Anatomy of an Agent

An autonomous agent generally consists of four main components:

  1. Brain (Model): The core LLM that handles reasoning and decision-making.
  2. Planning: Breaking down complex goals into manageable sub-tasks (Chain of Thought, Tree of Thoughts).
  3. Memory: Short-term (context window) and Long-term (Vector DB/External logs) to maintain continuity.
  4. Tools: External capabilities (Google Search, Python Interpreter, SQL Engine) accessible via API.

The ReAct Loop

Thought → Action → Observation → Thought... until the final answer is reached.

🎤 Interview Q&A

Q1 What is the difference between a Chain and an Agent? +

Answer:

  • Chain: A hard-coded, sequential path of operations (e.g., Prompt A → Model → Process output). The developer decides the flow.
  • Agent: The LLM is the reasoning engine that decides which tools to call and in what order based on the user's input. The flow is dynamic and decided by the model.
Q2 How do you handle 'Hallucinated Tool Calls'? +

Answer:

  1. Force Structured Output: Use OpenAI Function Calling or Pydantic models to ensure the JSON matches the expected schema.
  2. Error Correction Loop: If the tool call fails, send the traceback back to the LLM so it can "self-correct" and try again.
  3. Few-shot Examples: Provide examples in the prompt showing correct vs incorrect tool usage.

💻 Implementation Idea (LangChain)

Python Defining a Simple Search Agent 
from langchain_openai import ChatOpenAI
from langchain.agents import create_openai_functions_agent, AgentExecutor
from langchain import hub

# 1. Load the "ReAct" prompt template
prompt = hub.pull("hwchase17/openai-functions-agent")

# 2. Define the Model and Tools
llm = ChatOpenAI(model="gpt-4", temperature=0)
tools = [SearchTool(), CalculatorTool()]

# 3. Create the Agent
agent = create_openai_functions_agent(llm, tools, prompt)

# 4. Executor handles the loop (Agent Decisions -> Tool Exec -> Feedback)
agent_executor = AgentExecutor(agent=agent, tools=tools, verbose=True)

agent_executor.invoke({"input": "Search for the current weather in Paris and multiply it by 2."})

✍️ Practice Problem

Scenario: You have multiple agents working together (Multi-Agent). One agent's output is consistently poor, making the whole chain fail. How do you triage this?

  1. Tracing: Use LangSmith to isolate the specific agent trace.
  2. Unit Testing: Run that specific agent on a fixed dataset of inputs to see where its reasoning breaks.
  3. Prompt Optimization: Check if the system prompt is too broad or if it needs clearer "Stop Sequences" to prevent runaway generation.
  4. Switch Models: If reasoning is too complex, upgrade that specific expert to a better model (e.g., GPT-3.5 to GPT-4).
