📖 Key Concepts

1. Tensors & Device Agnosis

PyTorch tensors are similar to NumPy arrays but can run on GPUs (MPS/CUDA). Always write device-agnostic code.

device = "cuda" if torch.cuda.is_available() else "cpu"
tensor = torch.randn(3, 3).to(device)

2. The Training Loop

A standard PyTorch training loop consists of five key steps:

  1. Forward Pass: Compute predictions
  2. Calculate Loss: Compare predictions to ground truth
  3. Optimizer.zero_grad(): Clear previous gradients
  4. Loss.backward(): Backpropagation (compute gradients)
  5. Optimizer.step(): Update weights (Gradient Descent)

3. Module vs Functional

torch.nn contains stateful layers (with weights), while torch.nn.functional contains stateless operations (like activations).

💻 Implementation Example

Python Defining and Training a Simple MLP 
import torch
import torch.nn as nn
import torch.optim as optim

# 1. Define Architecture
class SimpleMLP(nn.Module):
    def __init__(self, input_size, hidden_size, output_size):
        super().__init__()
        self.network = nn.Sequential(
            nn.Linear(input_size, hidden_size),
            nn.ReLU(),
            nn.Linear(hidden_size, output_size)
        )
    
    def forward(self, x):
        return self.network(x)

# 2. Setup
model = SimpleMLP(input_size=10, hidden_size=64, output_size=1)
optimizer = optim.Adam(model.parameters(), lr=0.001)
criterion = nn.MSELoss()

# 3. Dummy Training Step
X = torch.randn(32, 10)
y = torch.randn(32, 1)

model.train()
optimizer.zero_grad()
outputs = model(X)
loss = criterion(outputs, y)
loss.backward()
optimizer.step()

print(f"Loss: {loss.item():.4f}")

🎤 Interview Q&A

Q1 What is the difference between .detach() and .numpy()? +

Answer:

  • .detach() creates a new tensor that shares storage but doesn't require gradients (breaks the computation graph).
  • .numpy() converts a tensor to a NumPy array. Important: You can only call .numpy() on CPU tensors that don't require gradients. Usually, you use tensor.detach().cpu().numpy().
Q2 Why do we need optimizer.zero_grad()? +

Answer:

PyTorch accumulates gradients by default (adds current gradients to existing ones). This is useful for things like Gradient Accumulation (simulating larger batch sizes). For standard training, we must clear them every step to avoid using gradients from the previous batch.

class MyLinear(nn.Module):
