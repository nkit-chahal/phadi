📌 Quick Summary

🎯
Object Detection

Locating multiple objects with bounding boxes. One-stage (YOLO, SSD) vs Two-stage (Faster R-CNN).

🧩
Segmentation

Classifying pixels. Semantic (all cars) vs Instance (individual car 1, car 2) vs Panoptic (everything).

🏗️
Backbones & Necks

ResNet/EfficientNet as feature extractors. FPN/PAN as feature aggregators for multi-scale detection.

📖 Detection Evolution

1. YOLO (You Only Look Once)

Splits image into a grid. Each cell predicts boxes and probabilities. Optimized for speed (real-time). YOLOv8/v10 are current state-of-the-art.

2. Loss Functions in Detection

  • Localization Loss: IoU Loss, GIoU, DIoU, CIoU (handles overlap better).
  • Classification Loss: Focal Loss (handles foreground-background imbalance).

3. Self-Supervised Learning (SSL)

Learning from unlabeled data using pretext tasks (e.g., Rotation prediction, Contrastive Learning like SimCLR/MoCo).

🎤 Interview Q&A

Q1 Explain NMS (Non-Maximum Suppression). +

Answer:

NMS is used to filter redundant overlapping bounding boxes. It keeps the box with the highest confidence and removes all others that have an IoU > threshold with that box. This ensures only one detection per object.

Q2 How do you handle small object detection? +

Answer:

  1. Increase input resolution.
  2. Feature Pyramid Networks (FPN): Combine low-level high-res features with high-level semantic features.
  3. Tiling: Crop image into smaller patches for inference.
  4. Anchor tuning: Use smaller anchors.

✍️ Practice Problem

Difference between Semantic and Instance Segmentation?

Semantic Segmentation classifies pixels into classes (e.g., all pixels belonging to 'people' get the same label). Instance Segmentation distinguishes individual objects within a class (e.g., 'Person 1', 'Person 2' get different labels).
