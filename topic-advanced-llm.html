📖 Key Architectural Innovations

1. RoPE (Rotary Positional Embedding)

A method to inject positional information by rotating query/key vectors in a complex plane. Used in Llama models. Allows better extrapolation to long contexts.

2. GQA (Grouped Query Attention)

A middle ground between Multi-Head (MHA) and Multi-Query (MQA). Shares key/value heads across multiple query heads to reduce KV cache size and memory bandwidth.

3. MoE (Mixture of Experts)

Only a fraction of the model (the 'experts') is activated for any given token. Allows models to have massive parameter counts (e.g., Mixtral 8x7B) with the inference cost of much smaller models.

🎤 Interview Q&A

Q1 What is the Chinchilla Scaling Law? +

Answer:

It states that for an optimal model, the number of training tokens should scale linearly with the number of parameters. Most models were 'under-trained' before this finding (e.g., Llama 7B was trained on 1T+ tokens, far exceeding Chinchilla recommendations to maximize inference efficiency).

Q2 Explain DPO (Direct Preference Optimization). +

Answer:

DPO is an alternative to RLHF that eliminates the need for a separate reward model and complex reinforcement learning (PPO). It directly optimizes the LLM based on preference pairs (Chosen vs Rejected) using a simple binary cross-entropy loss, making training more stable and computationally efficient.

✍️ Practice Problem

How does KV Caching speed up inference?

During autoregressive decoding, the Key and Value vectors for all previous tokens remain constant. Instead of recomputing them every time a new token is generated, we store (cache) them, reducing the computation from O(N²) to O(N) per step.
