📖 Advanced Drift Detection

1. PSI (Population Stability Index)

Measures how much the distribution of a variable has changed between two points in time.

  • PSI < 0.1: Stable, no action needed.
  • 0.1 < PSI < 0.25: Slight drift, investigate.
  • PSI > 0.25: Significant drift, retrain model.

2. Statistical Tests

  • Kolmogorov-Smirnov (KS) Test: Non-parametric test for comparing two distributions.
  • KL Divergence: Measures how one probability distribution differs from a second reference distribution.

3. Monitoring Tooling

Prometheus + Grafana for time-series metrics. Evidently AI / WhyLabs for ML-specific drift reports.

🎤 Interview Q&A

Q1 What is the difference between Data Drift and Concept Drift? +

Answer:

  • Data Drift (Covariate Shift): P(X) changes. The distribution of input features changes, but the relationship between input and output stays the same. (e.g., users getting younger).
  • Concept Drift: P(Y|X) changes. The relationship between input and output changes. (e.g., spending habits change during a recession).
Q2 How do you monitor model performance if labels are delayed? +

Answer:

  1. Monitor Data Drift as a proxy for performance degradation.
  2. Monitor Output Distribution Drift (is the model predicting more 'Spam' than usual?).
  3. Use Proxy Metrics (e.g., Click-Through Rate is a fast proxy for Relevance in Search).
  4. Statistical validation on a small human-labeled sample.

✍️ Practice Problem

Scenario: Your churn model's precision dropped from 80% to 50% in production, but its accuracy stayed at 90%. What could be happening?

This suggests Class Imbalance issues or Concept Drift. The model might be predicting the majority class (No Churn) to maintain high accuracy, but it's failing to identify the minority class (Churn) correctly, leading to high False Positives. Investigation: check confusion matrix and class distribution drift.
