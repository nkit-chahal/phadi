Activation Functions

Introducing non-linearity to neural networks

🔑 Common Functions

Function Range Pros Cons
Sigmoid (0, 1) Good for probability output Vanishing gradient, not zero-centered
Tanh (-1, 1) Zero-centered Vanishing gradient
ReLU [0, ∞) Fast computation, no vanishing grad for +ve Dying ReLU (dead neurons)
Leaky ReLU (-∞, ∞) Fixes Dying ReLU Extra parameter to tune
Softmax (0, 1) sum=1 Multi-class classification Only for output layer

✨ Modern Activations (Transformers)

Swish (Google)

f(x) = x * sigmoid(x)

Self-gated activation function. Smooth, non-monotonic. Outperforms ReLU in deep networks.

GELU (Gaussian Error Linear Unit)

f(x) ≈ x * Φ(x)

Used in BERT, GPT-3, ViT. Weighs inputs by their magnitude. Smooth curve allows better gradient flow than ReLU's sharp corner.

⚠️ Critical Problems

1. Vanishing Gradient

Cause: In Sigmoid/Tanh, large inputs saturate (gradient ≈ 0). During backprop, gradients multiply via chain rule. 0.1 * 0.1 * 0.1 ... ≈ 0.

Effect: Early layers stop learning.

Fix: Use ReLU, Residual Connections (ResNet), Batch Normalization.

2. Dying ReLU

Cause: If a neuron outputs < 0, gradient is 0. Weights cease to update. If learning rate is too high, many neurons may "die" .

Fix: Leaky ReLU, lower learning rate.
