Regularization

Techniques to prevent overfitting and improve generalization

📌 Quick Summary

📐
L1 (Lasso)

Sparse weights → Feature selection. Some weights become exactly 0.

📏
L2 (Ridge)

Small weights → Prevents any feature from dominating. All weights shrink.

🎲
Dropout

Random neuron deactivation → Ensemble effect in neural networks.

📖 Regularization Techniques

L1 Regularization (Lasso)

Loss = Original Loss + λ × Σ|wᵢ|
  • Effect: Drives some weights to exactly zero
  • Use case: Feature selection, sparse models
  • When: You suspect many features are irrelevant

L2 Regularization (Ridge / Weight Decay)

Loss = Original Loss + λ × Σwᵢ²
  • Effect: Shrinks all weights toward zero (but not exactly zero)
  • Use case: General regularization, prevent overfitting
  • When: Default choice for most ML problems

Elastic Net

Loss = Original Loss + λ₁×Σ|wᵢ| + λ₂×Σwᵢ²
  • Combines L1 and L2
  • Useful when features are correlated

Dropout

  • Randomly sets neurons to 0 during training (typically p=0.5)
  • At inference: all neurons active, weights scaled by (1-p)
  • Why it works: Prevents co-adaptation, creates ensemble effect

Early Stopping

  • Stop training when validation loss stops improving
  • Simple but effective
  • Use patience parameter to avoid stopping too early

Data Augmentation

  • Artificially expand training data
  • Images: Rotation, flip, crop, color jitter
  • Text: Synonym replacement, back-translation

Batch Normalization

  • Normalizes layer inputs → Has regularization effect
  • Often allows reducing or removing dropout

💻 Code Examples

Python L1 and L2 in Scikit-learn 
from sklearn.linear_model import Lasso, Ridge, ElasticNet

# L1 Regularization (Lasso)
lasso = Lasso(alpha=0.1)  # alpha is regularization strength
lasso.fit(X_train, y_train)
print(f"Non-zero features: {sum(lasso.coef_ != 0)}")  # Sparse!

# L2 Regularization (Ridge)
ridge = Ridge(alpha=1.0)
ridge.fit(X_train, y_train)
print(f"Max weight: {max(abs(ridge.coef_))}")  # All weights small

# Elastic Net (L1 + L2)
elastic = ElasticNet(alpha=0.1, l1_ratio=0.5)  # 50% L1, 50% L2
elastic.fit(X_train, y_train)

Python L2 Regularization (Weight Decay) in PyTorch 
import torch.optim as optim

# Method 1: Weight decay in optimizer
optimizer = optim.Adam(model.parameters(), lr=0.001, weight_decay=1e-4)

# Method 2: Manual L2 loss (more control)
def train_step(model, data, target, optimizer, l2_lambda=0.01):
    optimizer.zero_grad()
    output = model(data)
    
    # Original loss
    loss = F.cross_entropy(output, target)
    
    # Add L2 penalty
    l2_reg = torch.tensor(0.)
    for param in model.parameters():
        l2_reg += torch.norm(param, 2)
    
    total_loss = loss + l2_lambda * l2_reg
    total_loss.backward()
    optimizer.step()
    
    return total_loss.item()

🎤 Interview Questions & Answers

Q1 What's the difference between L1 and L2 regularization? +

Answer:

  • L1 (Lasso): Adds |w| to loss → Creates sparse weights (some become exactly 0) → Good for feature selection
  • L2 (Ridge): Adds w² to loss → Shrinks all weights toward 0 (but not exactly 0) → Good for general regularization

Geometric intuition: L1 constraint region is a diamond (corners at axes), L2 is a circle. Optimal solution more likely to hit L1 corners (sparse).

Q2 How does Dropout prevent overfitting? +

Answer:

  • Prevents co-adaptation: Neurons can't rely on specific other neurons
  • Ensemble effect: Training many "thinned" networks, averaging at test time
  • Adds noise: Similar to data augmentation for weights

Key detail: At test time, dropout is OFF but weights are scaled by (1-p) to maintain expected output magnitude.

Q3 When would you choose Early Stopping over other regularization? +

Answer:

Early stopping is great when:

  • You have limited compute and can't afford full hyperparameter search
  • Combined with other regularization techniques
  • You want a simple, effective baseline

Drawback: You might stop before reaching a good solution if training curve is noisy. Use patience parameter to mitigate.

Q4 How did you handle regularization in your projects? +

Answer (Personalized for Ankit):

In my YOLOv5 defect detection at Lincode:

  • Weight decay: 0.0005 (standard for YOLO)
