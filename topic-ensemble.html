Ensemble Methods

Bagging, Boosting, and Stacking explained

📌 Quick Summary

🎒
Bagging (Bootstrap Aggregating)

Train parallel independent models on random subsets. Reduces Variance. (e.g., Random Forest)

🚀
Boosting

Train sequential models, each correcting previous errors. Reduces Bias. (e.g., XGBoost, AdaBoost)

🌲 Random Forest vs XGBoost

Feature Random Forest (Bagging) XGBoost (Boosting)
Building Independent parallel trees Sequential trees (additive)
Goal Reduce Variance (Overfitting) Reduce Bias (Underfitting)
Tree Depth Deep (fully grown) Shallow (weak learners)
Outliers Robust Sensitive (tries to fix them)
Speed Faster training (parallel) Slower training (sequential)

🔑 Key Concepts

1. Gradient Boosting (GBM)

Uses gradient descent to optimize the loss function. Each new tree predicts the **residuals** (errors) of the previous tree.

Pred_new = Pred_old + learning_rate * Error_prediction

2. XGBoost Features

  • Regularization: L1/L2 built-in (prevents overfitting).
  • Handling Nulls: Automatically learns default direction for missing values.
  • Parallelism: Parallelizes tree construction (block design), not tree building itself.

3. Stacking

Train multiple different models (SVM, RF, Neural Net) and use a "Meta-Learner" (usually Logistic Regression) to make final prediction based on their outputs.

🎤 Interview Questions

Q1 Why does Random Forest not overfit easily?

Because it averages multiple uncorrelated trees. The variance of the average of N i.i.d random variables is Var(X)/N. More trees = less variance.

Q2 When would you use LightGBM over XGBoost?

LightGBM is faster and uses less memory. It uses GOSS (Gradient-based One-Side Sampling) and EFB (Exclusive Feature Bundling). Prefer it for massive datasets where speed is critical.
