LLM Inference & Optimization

Running Large Language Models efficiently: Quantization, vLLM, and Attention

📌 Core Concepts

📉
Quantization

Reducing precision (weights) from FP16 (2 bytes) to INT8, INT4, or NF4 to save VRAM and increase speed.

🏎️
Attention Optimization

Techniques like FlashAttention and PagedAttention to overcome the memory bottleneck of the Self-Attention mechanism.

1. Quantization Techniques

QLoRA (Quantized LoRA)

Great for Fine-tuning on consumer hardware.

  • 4-bit Normal Float (NF4): Information-theoretically optimal quantization for normally distributed weights.
  • Double Quantization: Quantizing the quantization constants themselves.
  • Paged Optimizers: Offloading optimizer states to CPU RAM when GPU OOMs.

GPTQ & AWQ (Post-Training Quantization)

Great for Inference only.

  • GPTQ (Generative Pre-trained Transformer Quantization): Layer-wise quantization that adjusts remaining weights to compensate for error. Fast decoding.
  • AWQ (Activation-aware Weight Quantization): Protects 1% of salient weights (based on activation magnitude) by keeping them in FP16. Better accuracy than GPTQ.

2. Throughput Optimization

vLLM & PagedAttention

The problem: KV Cache (Key-Value) memory grows dynamically. Standard systems pre-allocate contiguous chunks, leading to fragmentation and waste (60-80% wasted VRAM).

The solution (PagedAttention): Inspired by OS Virtual Memory. Blocks of KV cache are stored in non-contiguous memory spaces. The "Block Table" maps logical tokens to physical blocks.

  • Result: Near-zero memory waste.
  • Benefit: Can fit much larger batches -> 2-4x higher throughput.

FlashAttention-2

The problem: Attention is quadratic O(N²). Moving matrices between High-Bandwidth Memory (HBM) and GPU SRAM is the bottleneck.

The solution: Tiling. Compute attention in small tiles that fit in SRAM. Recompute stats avoiding HBM access.

  • Result: Linear scaling with sequence length.
  • Benefit: Faster training and inference for long contexts.

💻 Code Example: vLLM

Python Running vLLM engine 
from vllm import LLM, SamplingParams

# 1. Initialize Engine (loads model, manages PagedAttention)
llm = LLM(model="meta-llama/Llama-2-7b-hf")

# 2. Define prompts
prompts = [
    "Hello, my name is",
    "The president of the United States is",
    "The capital of France is",
]

# 3. Define sampling parameters
sampling_params = SamplingParams(temperature=0.8, top_p=0.95)

# 4. Generate (Batched)
outputs = llm.generate(prompts, sampling_params)

# Print results
for output in outputs:
    prompt = output.prompt
    generated_text = output.outputs[0].text
    print(f"Prompt: {prompt!r}, Generated text: {generated_text!r}")
