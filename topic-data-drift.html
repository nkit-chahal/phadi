Data Drift & PSI

Detecting when your model becomes stale in production

📌 Quick Summary

📊
Data Drift

Input distribution P(X) changes. "Users are younger now."

🧠
Concept Drift

Relationship P(Y|X) changes. "Same users, but they buy different things."

📐
PSI (Population Stability Index)

Metric to quantify drift. PSI > 0.25 = Critical.

📐 PSI (Population Stability Index)

The industry standard for measuring distribution shift. It compares the distribution of a feature in specific "buckets" (bins) between a reference population (training) and current population (production).

PSI = Σ ( (Actual% - Expected%) × ln(Actual% / Expected%) )
PSI Value Interpretation Action
< 0.1 No significant drift No action needed
0.1 - 0.25 Moderate drift Monitor closely
> 0.25 Significant drift Retrain model

How to Calculate PSI (Step-by-Step)

  1. Divide the **Training Data** (Expected) into 10 equal buckets (deciles).
  2. Apply same bucket boundaries to **Production Data** (Actual).
  3. Calculate % of samples in each bucket for both.
  4. Apply formula: (A% - E%) * ln(A% / E%) for each bucket.
  5. Sum up all buckets.

💻 Python Implementation

Python Calculating PSI from scratch 
import numpy as np

def calculate_psi(expected, actual, buckettype='bins', buckets=10, axis=0):
    '''Calculate the PSI (Population Stability Index) for two arrays'''
    
    def psi(expected_array, actual_array, buckets):
        def scale_range(input, min, max):
            input += -(np.min(input))
            input /= np.max(input) / (max - min)
            input += min
            return input

        breakpoints = np.arange(0, buckets + 1) / (buckets) * 100

        if buckettype == 'bins':
            breakpoints = np.percentile(expected_array, breakpoints)
        
        expected_percents = np.histogram(expected_array, breakpoints)[0] / len(expected_array)
        actual_percents = np.histogram(actual_array, breakpoints)[0] / len(actual_array)

        # Avoid div by zero
        expected_percents = np.where(expected_percents == 0, 0.0001, expected_percents)
        actual_percents = np.where(actual_percents == 0, 0.0001, actual_percents)

        psi_value = np.sum((actual_percents - expected_percents) * np.log(actual_percents / expected_percents))
        return psi_value

    return psi(expected, actual, buckets)

# Usage
train_ages = np.random.normal(30, 5, 1000)
prod_ages = np.random.normal(35, 5, 1000)  # Drifted!

psi_score = calculate_psi(train_ages, prod_ages)
print(f"PSI Score: {psi_score:.4f}")
# Output: PSI Score likely > 0.25 due to mean shift

🔍 Other Drift Detection Methods

1. KS Test (Kolmogorov-Smirnov)

Statistical test to check if two samples come from the same distribution.

  • Null Hypothesis (H0): Distributions are same.
  • If p-value < 0.05, reject H0 → **Drift Detected**.
  • Good for numerical features.

2. KL Divergence (Kullback-Leibler)

Measures how one probability distribution differs from a second, reference probability distribution. Not symmetric (unlike JS Divergence).

3. JS Divergence (Jensen-Shannon)

Symmetric and smooth version of KL Divergence. Always between 0 and 1.
