Optimizers

Algorithms that update model weights to minimize loss

📌 Quick Summary

🐢
SGD

Simple, needs tuning. Add momentum for speed.

⚡
Adam

Default choice. Adaptive LR + momentum. Works out of the box.

🤖
AdamW

Adam + proper weight decay. Best for Transformers/LLMs.

📖 Optimizer Comparison

SGD (Stochastic Gradient Descent)

w = w - lr × ∇L(w)
  • Pros: Simple, well-understood, good generalization
  • Cons: Slow convergence, sensitive to learning rate
  • Tip: Use with momentum (0.9) and learning rate scheduling

SGD with Momentum

v = β×v + ∇L(w) | w = w - lr×v
  • Momentum helps escape local minima and speeds up convergence
  • β typically 0.9 (accumulates 90% of previous velocity)

Adam (Adaptive Moment Estimation)

m = β₁×m + (1-β₁)×g | v = β₂×v + (1-β₂)×g²
  • Combines: Momentum (m) + RMSprop (v)
  • Adaptive LR: Different learning rate per parameter
  • Defaults: β₁=0.9, β₂=0.999, lr=0.001
  • Best for: Most deep learning tasks, quick prototyping

AdamW

  • Fix: Decouples weight decay from gradient update
  • Why it matters: Proper L2 regularization in Adam
  • Best for: Transformers, BERT, GPT, LLMs

RMSprop

  • Adaptive learning rate per parameter
  • Good for RNNs with non-stationary problems
  • Predecessor to Adam

Python PyTorch Optimizers 
import torch.optim as optim

model = YourModel()

# SGD with momentum
optimizer = optim.SGD(model.parameters(), lr=0.01, momentum=0.9)

# Adam (default choice)
optimizer = optim.Adam(model.parameters(), lr=0.001)

# AdamW (for Transformers)
optimizer = optim.AdamW(model.parameters(), lr=1e-4, weight_decay=0.01)

# Training loop
for epoch in range(epochs):
    optimizer.zero_grad()      # Clear gradients

    loss.backward()            # Backward pass
    optimizer.step()           # Update weights
Python Learning Rate Schedulers 
from torch.optim.lr_scheduler import (
    StepLR, CosineAnnealingLR, ReduceLROnPlateau
)

optimizer = optim.Adam(model.parameters(), lr=0.001)

# Step decay: reduce LR by 0.1 every 30 epochs
scheduler = StepLR(optimizer, step_size=30, gamma=0.1)

# Cosine annealing: smooth decay (popular for vision)
scheduler = CosineAnnealingLR(optimizer, T_max=100)

# Reduce on plateau: reduce when metric stops improving
scheduler = ReduceLROnPlateau(optimizer, patience=5, factor=0.5)

# In training loop:
for epoch in range(epochs):
    train(...)
    val_loss = validate(...)
    
    # For most schedulers:
    scheduler.step()
    
    # For ReduceLROnPlateau:
    scheduler.step(val_loss)

🎤 Interview Questions & Answers

Q1 Why use Adam over SGD? +

Answer:

  • Adaptive learning rates: Adam adjusts LR per parameter based on gradient history
  • Faster convergence: Usually converges faster than SGD
  • Less tuning: Default hyperparameters work well

When to use SGD instead:

  • Final training for better generalization (SGD sometimes generalizes better)
  • When you have time for extensive hyperparameter tuning
  • Some research shows SGD + momentum finds flatter minima
Q2 What is AdamW and why is it used for Transformers? +

Answer:

AdamW decouples weight decay from the gradient update. In standard Adam, weight decay is implemented incorrectly as L2 regularization added to the loss, which interacts poorly with the adaptive learning rates.

AdamW applies weight decay directly to weights: w = w - lr × (grad + wd × w)

Why for Transformers:

  • Transformers have many parameters and need proper regularization
  • BERT, GPT papers use AdamW
  • Combined with warmup, gives stable training
Q3 What is learning rate warmup? +

Answer:

Warmup gradually increases learning rate from 0 to the target value over the first few steps/epochs.

Why it helps:

  • Prevents large early updates when gradients are unstable
  • Allows model to "settle" before aggressive updates
  • Critical for Transformers and large batch training

Common pattern: Linear warmup for 5-10% of training, then cosine decay or linear decay.

Q4 What optimizer did you use in your projects? +

Answer (Example Answer):

  • YOLOv5 (Lincode): SGD with momentum (0.937) + cosine annealing. YOLO authors found SGD generalizes better for object detection.
  • RAG/LLM fine-tuning (Trident): AdamW with linear warmup, weight decay 0.01, LR 2e-5. Standard for transformer-based models.
  • Quick prototyping: Adam with default parameters - fast iteration.
