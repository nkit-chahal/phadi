ML Testing Strategies

The Testing Pyramid: Data, Model, and Infrastructure tests

📌 The ML Testing Pyramid

      /   Model Performance  \   (Accuracy, F1, Bias)
     /     Model Integrity    \  (Shape check, NaNs)
    /        Data Validation    \ (Schema, Nulls, Ranges)
   /      Unit & Infra Tests     \ (Code logic, API Health)
  ---------------------------------

1. Data Tests (The Foundation)

Garbage In, Garbage Out. Verify data before it hits your model.

  • Schema: Are columns present? Types correct?
  • Completeness: Are critical features missing (Nulls)?
  • Validity: Is age > 0? Is probability between 0 and 1?

2. Model Integrity Tests

Verify the model artifact works technically.

  • Input/Output shape: Does model accept (B, 3, 224, 224)?
  • Staleness: Is the model file older than 24 hours?
  • Sanity: Does it predict constant class for all inputs? (Bug)

3. Performance Tests

Verify the model is actually "smart".

  • Golden Set: Test on curated set of important examples.
  • Minimum Accuracy Threshold: Fail build if Acc < 0.85.
  • Bias/Slicing: Check accuracy on sub-groups (e.g., performance on "US Users" vs "EU Users").

💻 Code Example: Great Expectations

Python Data Validation 
import great_expectations as ge

df = ge.read_csv("data.csv")

# 1. Expect column to exist
df.expect_column_to_exist("user_age")

# 2. Expect values to be in range
df.expect_column_values_to_be_between(
    "user_age", 
    min_value=0, 
    max_value=120
)

# 3. Expect no nulls
df.expect_column_values_to_not_be_null("user_id")

# Run validation
results = df.validate()
if not results["success"]:
    raise ValueError("Data Quality Check Failed!")
