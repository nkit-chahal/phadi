📈 Regression Loss Functions

Mean Squared Error (MSE / L2 Loss)

MSE = (1/n) × Σ(yᵢ - ŷᵢ)²
  • When to use: General regression, differentiable everywhere
  • Pros: Penalizes large errors heavily, smooth gradients
  • Cons: Sensitive to outliers (squares them!)

Mean Absolute Error (MAE / L1 Loss)

MAE = (1/n) × Σ|yᵢ - ŷᵢ|
  • When to use: When outliers are present
  • Pros: Robust to outliers
  • Cons: Gradient is constant (doesn't scale with error), not differentiable at 0

Huber Loss (Smooth L1)

Huber = { ½(y-ŷ)² if |y-ŷ| ≤ δ, δ(|y-ŷ| - ½δ) otherwise }
  • When to use: Best of both MSE and MAE
  • Pros: Robust to outliers, differentiable everywhere
  • Cons: Extra hyperparameter δ to tune

🎯 Classification Loss Functions

Binary Cross-Entropy (Log Loss)

BCE = -[y·log(ŷ) + (1-y)·log(1-ŷ)]
  • When to use: Binary classification (2 classes)
  • Output: Sigmoid activation → probability [0, 1]
  • Heavily penalizes confident wrong predictions

Categorical Cross-Entropy

CCE = -Σ yᵢ·log(ŷᵢ) over all classes
  • When to use: Multi-class classification (one-hot encoded)
  • Output: Softmax activation → probability distribution

Sparse Categorical Cross-Entropy

  • Same as CCE but labels are integer indices (not one-hot)
  • More memory efficient for many classes

Focal Loss

FL = -αₜ(1-pₜ)^γ·log(pₜ)
  • When to use: Highly imbalanced datasets, object detection
  • How it works: Down-weights easy examples, focuses on hard negatives
  • γ (gamma): Focusing parameter (typically 2)
  • α (alpha): Class balancing weight
  • Used in RetinaNet for object detection

💻 Code Examples

Python Regression Losses in PyTorch 
import torch
import torch.nn as nn

# Sample data
y_true = torch.tensor([3.0, 5.0, 2.5, 7.0])
y_pred = torch.tensor([2.5, 5.5, 2.0, 8.0])

# MSE Loss
mse_loss = nn.MSELoss()
print(f"MSE: {mse_loss(y_pred, y_true):.4f}")

# MAE Loss (L1)
mae_loss = nn.L1Loss()
print(f"MAE: {mae_loss(y_pred, y_true):.4f}")

# Huber Loss (Smooth L1)
huber_loss = nn.SmoothL1Loss()
print(f"Huber: {huber_loss(y_pred, y_true):.4f}")

# Custom Huber with delta
def custom_huber(y_true, y_pred, delta=1.0):
    error = torch.abs(y_true - y_pred)
    quadratic = torch.clamp(error, max=delta)
    linear = error - quadratic
    return torch.mean(0.5 * quadratic**2 + delta * linear)
Python Classification Losses in TensorFlow/Keras 
import tensorflow as tf
from tensorflow.keras.losses import (
    BinaryCrossentropy,
    CategoricalCrossentropy,
    SparseCategoricalCrossentropy
)

# Binary Classification
bce = BinaryCrossentropy()
y_true_binary = [1, 0, 1, 1]
y_pred_binary = [0.9, 0.1, 0.8, 0.7]
print(f"BCE: {bce(y_true_binary, y_pred_binary):.4f}")

# Multi-class (one-hot)
cce = CategoricalCrossentropy()
y_true_onehot = [[1, 0, 0], [0, 1, 0], [0, 0, 1]]
y_pred_probs = [[0.9, 0.05, 0.05], [0.1, 0.8, 0.1], [0.2, 0.2, 0.6]]
print(f"CCE: {cce(y_true_onehot, y_pred_probs):.4f}")

# Multi-class (integer labels) - more memory efficient
scce = SparseCategoricalCrossentropy()
y_true_int = [0, 1, 2]  # Class indices
print(f"Sparse CCE: {scce(y_true_int, y_pred_probs):.4f}")
Python Focal Loss Implementation 
import torch
import torch.nn as nn
import torch.nn.functional as F

class FocalLoss(nn.Module):
    """
    Focal Loss for imbalanced classification.
    Used in object detection (RetinaNet) and imbalanced datasets.
    """
    def __init__(self, alpha=0.25, gamma=2.0):
        super().__init__()
        self.alpha = alpha  # Class weight
        self.gamma = gamma  # Focusing parameter
    
    def forward(self, inputs, targets):
        # inputs: logits, targets: class labels
        bce_loss = F.binary_cross_entropy_with_logits(
            inputs, targets, reduction='none'
        )
        
        # Get probabilities
        p = torch.sigmoid(inputs)
        p_t = p * targets + (1 - p) * (1 - targets)
        
        # Apply focal weight
        focal_weight = (1 - p_t) ** self.gamma
        
        # Apply alpha weight
        alpha_t = self.alpha * targets + (1 - self.alpha) * (1 - targets)
        
        focal_loss = alpha_t * focal_weight * bce_loss
        return focal_loss.mean()

# Usage
focal = FocalLoss(alpha=0.25, gamma=2.0)
logits = torch.tensor([0.5, -1.0, 2.0])
targets = torch.tensor([1.0, 0.0, 1.0])
print(f"Focal Loss: {focal(logits, targets):.4f}")

🎤 Interview Questions & Answers

Q1 When would you use MAE over MSE? +

Answer:

Use MAE when:

  • Outliers are present: MAE is robust because it doesn't square errors
  • Errors should be weighted equally: A $10 error is 10x worse than $1 error (not 100x)
  • Interpretability matters: MAE is in the same units as the target

Use MSE when:

  • Large errors are particularly bad and should be heavily penalized
  • You need smooth gradients everywhere (MSE is differentiable at 0)
Q2 Why use Focal Loss in object detection? +

Answer:

Object detection has extreme class imbalance - most anchor boxes are background (negative), very few contain objects (positive).

  • Problem: Easy negatives dominate training, overwhelming the gradient
  • Solution: Focal Loss down-weights easy examples using (1-p)^γ term
  • When γ=2 and p=0.9 (easy example), weight is 0.01 (almost ignored)
  • When p=0.5 (hard example), weight is 0.25 (still contributes)

This allows the model to focus on hard-to-classify examples.

Q3 What's the difference between Categorical and Sparse Categorical Cross-Entropy? +

Answer:

  • Categorical: Labels are one-hot encoded [0, 0, 1, 0]
  • Sparse Categorical: Labels are integers [2]

They compute the same loss, but Sparse is more memory-efficient for datasets with many classes (like ImageNet with 1000 classes).

Q4 In your defect detection project, what loss did you use and why? +

Answer (Personalized for Ankit):

In my YOLOv5 defect detection at Lincode:

  • Classification Loss: BCE with class weights to handle rare defect types
  • Box Regression: CIoU Loss for better bounding box regression
  • Objectness: BCE to predict if anchor contains object

For rare defect classes, I also experimented with Focal Loss (γ=2) which improved recall on minority classes by 15%.
