Design personalized recommendation engines at scale

📌 Recommendation Architecture

User Request → Candidate Generation → Ranking → Re-ranking → Results
                    (1000s)           (100s)     (10s)        (N)

Stage 1: Fast, simple models (embeddings, rules)
Stage 2: Complex models with more features  
Stage 3: Business rules, diversity, freshness

📖 Recommendation Approaches

1. Collaborative Filtering

  • User-based: Similar users like similar items
  • Item-based: Similar items liked by same users
  • Matrix Factorization: SVD, ALS for implicit feedback
  • Pros: No content features needed
  • Cons: Cold start problem, sparsity

2. Content-Based Filtering

  • Use item features (genre, category, embeddings)
  • Match user profile to item profiles
  • Pros: Works for new items
  • Cons: Limited discovery, needs good features

3. Hybrid (Most Common)

  • Combine collaborative + content signals
  • Two-tower model: User tower + Item tower → dot product
  • Wide & Deep: Memorization + generalization

  • New users: Popular items, onboarding quiz, demographics

💻 Code Examples

Python Two-Tower Model (PyTorch) 
import torch
import torch.nn as nn

class TwoTowerModel(nn.Module):
    def __init__(self, num_users, num_items, embedding_dim=64):
        super().__init__()
        
        # User tower
        self.user_embedding = nn.Embedding(num_users, embedding_dim)
        self.user_mlp = nn.Sequential(
            nn.Linear(embedding_dim, 128),
            nn.ReLU(),
            nn.Linear(128, embedding_dim)
        )
        
        # Item tower
        self.item_embedding = nn.Embedding(num_items, embedding_dim)
        self.item_mlp = nn.Sequential(
            nn.Linear(embedding_dim, 128),
            nn.ReLU(),
            nn.Linear(128, embedding_dim)
        )
    
    def forward(self, user_ids, item_ids):
        # Get embeddings
        user_emb = self.user_embedding(user_ids)
        item_emb = self.item_embedding(item_ids)
        
        # Through MLPs
        user_vec = self.user_mlp(user_emb)
        item_vec = self.item_mlp(item_emb)
        
        # Dot product for similarity
        scores = (user_vec * item_vec).sum(dim=1)
        return torch.sigmoid(scores)
    
    def get_user_embedding(self, user_id):
        return self.user_mlp(self.user_embedding(user_id))
    
    def get_item_embedding(self, item_id):
        return self.item_mlp(self.item_embedding(item_id))

# Build index with item embeddings
item_embeddings = model.get_all_item_embeddings()  # [num_items, dim]

# Create FAISS index
index = faiss.IndexFlatIP(dimension)  # Inner product (for cosine after L2 norm)
faiss.normalize_L2(item_embeddings)
index.add(item_embeddings)

def get_candidates(user_id, k=100):
    """Retrieve top-K candidate items for user."""
    # Get user embedding
    user_emb = model.get_user_embedding(user_id).numpy()
    faiss.normalize_L2(user_emb.reshape(1, -1))
    
    # Search
    scores, indices = index.search(user_emb.reshape(1, -1), k)
    
    return list(zip(indices[0], scores[0]))

🎤 Interview Questions & Answers

Q1 Design a movie recommendation system. +

Answer Framework:

  1. Clarify: Netflix-scale? New users? Real-time?
  2. Metrics: Watch completion, CTR, time spent
  3. Data: Watch history, ratings, movie metadata
  4. Model:
    • Candidate gen: Two-tower embeddings
    • Ranking: Deep model with user/movie/context features
  5. Serving: Pre-compute candidates, real-time ranking
  6. Cold start: Popular movies, onboarding preferences
Q2 What is the cold start problem? +

Answer:

Difficulty recommending for new users or items with no interaction history.

Solutions:

  • New users: Demographics, onboarding quiz, popular items, explore
  • New items: Content features, creator history, boosting period
  • General: Explore/exploit balance, fallback to popularity
Q3 How do you ensure recommendation diversity? +

Answer:

  • Intra-list diversity: MMR (Maximal Marginal Relevance) re-ranking
  • Coverage metrics: Track % of catalog recommended
  • Category balancing: Ensure mix of genres/types
  • Explore slots: Reserve positions for discovery
